# مجلد البيانات (data/)

هذا المجلد يحوي **بيانات التشغيل الفعلية** (حوالات، دفتر الأستاذ، المستخدمون، سجلات التدقيق)، ولا تُرفع إلى Git (انظر `.gitignore`).

- تُنشأ الملفات تلقائياً عند أول تشغيل إن لم تكن موجودة.
- **انسخ هذا المجلد احتياطياً بانتظام** (الملفات `*.bak` نسخة سابقة من كل ملف).
- ملفات `*.example.json` أمثلة ببيانات وهمية للتوضيح فقط، ولا يقرؤها النظام.
